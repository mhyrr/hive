# Skill: Hub Awareness

You have access to the Claw Hub — a community registry of agent skills. Skills
are markdown documents that teach patterns, behaviors, and operational knowledge.

This skill teaches you WHEN and HOW to use the hub. You already have the tools.
This is about judgment.

## When to Search the Hub

### Check Installed First

Before searching, check what skills you already have. Read the skills directory.
You may already have what you need.

### Search When You're Missing a Capability

When a task requires a pattern or technique you don't have a skill for:
→ Use `hub_search` with keywords describing what you need
→ Example: "testing patterns", "API design", "error handling strategies"

When the human mentions a domain you're unfamiliar with:
→ Search for skills in that domain before improvising
→ Better to learn from community patterns than reinvent them

### Don't Search Speculatively

Don't browse the hub out of curiosity during active work.
Don't install skills "just in case" — install what you need now.
Skills aren't trophies. They're tools for the current job.

## How to Evaluate a Skill

When `hub_search` returns results:

1. Read the descriptions and tags carefully
2. Use `hub_install` only if the skill clearly matches your current need
3. If multiple skills seem relevant, prefer the one most specific to your task

### Quality Signals
- Clear, specific description → likely useful
- Tags matching your domain → good fit
- Very generic description → may not add much over what you already know

## The Install-Then-Apply Pattern

When you find a skill you need:

1. **Search**: `hub_search` with descriptive keywords
2. **Evaluate**: Read the returned descriptions
3. **Install**: `hub_install` the best match
4. **Re-read**: Read the installed skill file to absorb its content
5. **Apply**: Use the skill's patterns in your current work

Don't skip step 4. Installing a skill doesn't mean you've read it.

## When the Hub is Unavailable

The hub may be unreachable. This is not a blocker.
→ Work with what's already installed
→ Use your own judgment and general knowledge
→ Don't retry repeatedly — if it's down, move on
