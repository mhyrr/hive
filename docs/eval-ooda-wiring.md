`think` does not fully bootstrap the OODA tactical loop yet: it creates an `OrientationCache` but never calls `regenerate`, so `createEvaluatedWatcherEvents` falls through without evaluating signals while orientation is null. It does correctly stand up the watcher, context refresh, and eval-log plumbing, so the scaffold is in place. The strategic handoff is still a stub (`onStrategicTrigger` only logs), so ORIENT→INTEGRATE is not live from `hive think`. Tactical actions are also not live end-to-end yet: `routing.action === "tactical"` only logs a queued command and does not execute anything.

Gateway watcher wiring is closer to production: it refreshes runtime state, bootstraps orientation (including stale regeneration), and wraps raw watcher events through the evaluator. The main wiring bug is contract drift: `src/gateway/watcher.ts` builds a `DispatcherConfig` without `projectRunsActiveDir`, even though the dispatcher now uses that field for direct interrupts. That combines badly with the new dispatcher behavior, because the dispatcher already calls `interruptWorker` directly and the gateway `onInterruptRequest` callback calls it again, creating duplicate interrupt attempts. Net: gateway evaluation is mostly live but has an interrupt-path defect, while `think` is still mostly a pass-through until orientation bootstrap and strategic/tactical executors are wired.
